## 怎么打开（本地）

1. 用本地静态服务打开**本目录**（推荐，避免 `file://` 下 iframe 限制），例如在本目录执行：
   ```bash
   npx serve -l 8765 .
   ```
   浏览器打开：`http://localhost:8765/index.html`（建议带 `index.html` 或目录尾斜杠）
2. Cursor / VS Code：Live Server 打开本目录下的 `index.html`
3. 入口文件：`index.html`（壳会按自身所在目录解析子模块路径，可独立拷贝本文件夹）
4. 嵌壳子页以「目录 + 尾斜杠」加载（如 `价目表/`），避免部分静态服务器把路径收成无斜杠导致相对脚本失效
