# [我的订单] PRD

## 一、User Story
> 作为平台会员，我希望通过活动详情页的悬浮按钮进入我的订单列表，查看本人全部订单的状态、活动内容、商家信息及金额，以便掌握订单情况并进入订单详情。

## 二、Function Requirements

### F1 顶部导航
- **功能描述**：页面顶部展示返回按钮及「我的订单」标题。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 返回按钮返回活动详情页。

### F2 订单状态筛选
- **功能描述**：页面顶部提供订单状态筛选标签：全部、待支付、已支付、已使用、已退单。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 四种订单状态与门店侧团员订单状态的对应关系见《订单列表 PRD》F0 规则 10。
  2. 默认展示「全部」状态的订单。
  3. 切换筛选维度后，仅展示对应状态的订单。

### F3 订单列表
- **功能描述**：以卡片形式展示当前会员本人的订单列表。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 仅展示当前会员本人的订单，不展示其他会员的订单。
  2. 卡片字段：商家名称、订单状态、活动名称、活动说明、商家地址、下单日期、订单金额。
  3. 活动说明取值：已支付、已使用订单恒展示「已使用 x 份」（x 为各项目已使用份数之和，只保留已使用份数、不展示总份数；**已使用份数为 0 时同样展示「已使用 0 份」**，核销份数口径见《订单详情（门店侧）PRD》F9）；待支付、已退单订单展示「含 N 个项目」（N 为项目数）。各项目使用情况的完整口径与《订单详情（会员侧）PRD》F2 一致。列表不逐项展开项目，项数与各项目份数的完整展示仅在订单详情页（见《订单详情（会员侧）PRD》F2）。
  4. 订单按下单时间由近及远排序。
  5. 已退单订单额外展示「该订单已退单，如有疑问请联系商家」提示。
  6. 待支付订单逾期未支付的处理见《订单列表 PRD》F0 规则 11，逻辑删除后的订单不再展示。
  7. 订单卡片不展示分享/成团相关信息（相关规则见《活动详情 PRD》F6）。
  8. 当前会员无任何订单时，展示「暂无相关订单」空状态提示。

### F4 订单卡片操作
- **功能描述**：每张订单卡片底部提供对应的操作入口。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 「联系商家」对所有状态的订单展示，会员点击后直接拨打商家联系电话。
  2. 「去点评」仅对已使用状态的订单展示，点击后跳转至点评模块；点评相关规则不在本文档范围。
  3. 「去支付」仅对待支付状态的订单展示，用于会员完成支付。
  4. 已使用订单同时展示「联系商家」与「去点评」，并排一行；待支付订单同时展示「联系商家」与「去支付」，并排一行。

### F5 订单详情入口
- **功能描述**：每张订单卡片可进入对应订单的详情页。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 点击订单卡片进入该订单的详情页。
