# [联盟广场] PRD

## 一、User Story
> 作为门店店长，我希望浏览本市范围内的联盟活动，按门店、项目分类、项目名称、活动名称模糊搜索，并通过活动二维码引导客户参与活动，以便提升活动曝光、引导客户立即购买下单。

## 二、Function Requirements

### F1 顶部导航与分区导航
- **功能描述**：页面顶部展示「联盟广场」标题栏，下方提供「平台活动」「我的活动」「我的收藏」三个分区导航。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 分区导航固定三项：平台活动、我的活动、我的收藏，分别对应 F3、F4、F5 三个活动列表；同一时刻仅展示其中一个分区的列表内容。
  2. 进入页面时默认停留在「平台活动」分区。
  3. 搜索与门店筛选（见 F2）仅作用于「平台活动」分区，不作用于 F4「我的活动」与 F5「我的收藏」。

### F2 搜索与筛选
- **功能描述**：提供搜索框，支持按门店、项目分类、项目名称、活动名称搜索活动，并提供常用门店筛选标签。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 搜索支持门店、项目分类、项目名称、活动名称的模糊匹配。
  2. 门店筛选标签包含「全部」及平台各联盟活动所属门店。
  3. 搜索与门店筛选可组合使用：触发搜索后先清除筛选（定位到「全部」），并依据搜索结果缩小筛选范围。
  4. 门店筛选标签的展示顺序规则：收藏 > 距离 > 时间，最多 10 个；用户未授权定位、无法取得距离时，按默认顺序（收藏 > 时间）排列。
  5. 未找到匹配活动时，展示「未找到匹配的活动」。

### F3 平台联盟活动列表
- **功能描述**：以卡片形式展示本市范围内的平台联盟活动列表。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 活动数据范围限定为本市，仅展示本市门店发布的、已上架的联盟活动；排序规则：按活动发布时间由新到旧。
  2. 卡片字段：门店名称、活动名称、活动标签、活动类型、活动价格、活动原价、项目清单，以及收藏与「查看二维码」两个操作。
  3. 项目清单按活动配置的已选项目逐项展示：项目分类小标签、项目名称、项目数量、项目单价。
  4. 项目数量为门店配置活动时设置的项目份数（见《创建活动 PRD》F2），按「×份数」展示。本规则为项目清单展示口径的唯一来源，F4、F5 引用本规则。
  5. 活动标签与活动类型在同一行以标签形式展示，使用颜色区分：活动类型为主色标签、活动标签为灰色标签。本规则为标签展示样式的唯一口径，F4、F5 引用本规则。
  6. 活动类型标签按活动已开启的玩法展示：「优客圈」为默认玩法、始终展示；「老带新」开启后并列展示，两种玩法同时开启时两个标签同时展示。玩法取值见《活动配置 PRD》F4。
  7. 活动支持收藏与取消收藏，收藏后星标高亮。
  8. 每张卡片提供「查看二维码」按钮，与收藏按钮并排展示，点击弹出分享海报弹层（见 F6）。
  9. 活动价格、活动原价为活动售价与活动原价（计算规则见《活动配置 PRD》F5）。

### F4 我的活动列表
- **功能描述**：以卡片形式展示当前门店发布的联盟活动，点击卡片任意位置进入该活动的编辑流程。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 卡片字段：活动名称、活动标签、活动类型、活动价格、活动原价、折扣、上架/下架开关、项目清单，以及「查看二维码」操作。
  2. 活动状态分为「进行中」与「已下架」，由门店通过卡片上的上架/下架开关手动切换；开关开启为「进行中」，关闭为「已下架」。活动发布后默认上架（见《活动配置 PRD》F3）。下架不影响进入编辑页，可随时重新上架；重新上架后恢复联盟广场曝光与二维码可用。本规则为活动上/下架状态的唯一口径，F6 与《活动详情 PRD》F8 引用本规则。
  3. 点击卡片任意位置进入该活动的编辑流程，进入编辑页并预填该活动已保存的内容。
  4. 「查看二维码」与上架/下架开关并排展示，点击弹出该活动的分享海报弹层（见 F6）。
  5. 活动标签与活动类型的标签展示样式、颜色区分规则同 F3；项目清单展示口径同 F3 第 3、4 条。
  6. 活动价格、活动原价、折扣为活动售价、活动原价与折扣配置（计算规则见《活动配置 PRD》F5）。
  7. 未发布任何活动时，仅展示空状态提示「暂无发布的联盟活动」，不提供任何操作入口。

### F5 我的收藏列表
- **功能描述**：以卡片形式展示当前门店在联盟广场收藏的活动，卡片结构与联盟广场一致，提供取消收藏与「查看二维码」操作。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 收藏列表仅展示在联盟广场被收藏的活动。
  2. 支持取消收藏，取消后该活动从收藏列表移除。
  3. 「查看二维码」与收藏按钮并排展示，点击弹出该活动的分享海报弹层（见 F6）。
  4. 活动标签与活动类型的标签展示样式、颜色区分规则同 F3；项目清单展示口径同 F3 第 3、4 条。
  5. 未收藏任何活动时，仅展示空状态提示「暂无收藏的活动」，不提供任何操作入口。

### F6 分享海报弹层
- **功能描述**：点击卡片「查看二维码」后弹出分享海报弹层。弹层仅展示一张竖版（3:4）通用平台品牌海报（海报内含活动参与二维码），以及「前往活动详情」与「下载」两个操作；不展示标题、活动名称、所属门店等辅助信息。联盟广场、我的收藏与我的活动列表共用该弹层。本模块为活动二维码的唯一口径。
- **数据来源**：
  - 通用平台品牌海报图片由设计统一提供，规格为竖版（3:4）；Demo 阶段以占位符展示。海报品牌标识使用「优客圈」，与平台玩法名称保持一致。
  - 活动专属二维码由【RTB】生成，链接指向 C 端活动详情页。
- **业务规则**：
  1. 海报比例固定为 3:4，同一平台所有活动共用同一张海报。
  2. 海报内放置活动参与二维码，二维码内容为活动参与链接，链接地址格式为 https://rts.cn/act/{活动ID}；每个活动对应独立二维码，不同活动的二维码内容不同。
  3. 「下载」操作用于下载整张分享海报（含活动二维码）；「前往活动详情」进入该活动的 C 端活动详情页。
  4. 二维码不含分享人归因标识，扫码产生的订单不属于任何团（归因与成团规则见《订单列表 PRD》F0 规则 4、规则 12）。
  5. 二维码有效期随活动上/下架状态联动（见 F4 第 2 条）：活动下架后自动失效，扫码时提示「活动已结束」；活动重新上架后恢复可用。
  6. 正式版本由【RTB】直接生成二维码图片展示（Demo 阶段以占位样式展示）。
