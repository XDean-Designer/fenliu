# [创建活动] PRD

## 一、User Story
> 作为门店店长，我希望选择本店的服务项目和商品并设置数量，以便进入下一步配置活动并发布活动，供联盟广场展示及推荐给客户。

---

## 二、Function Requirements

### F1 发布规则说明
- **功能描述**：页面右上角提供规则说明入口，用于查看「发布活动」规则说明。
- **数据来源**：规则说明文案来源于【RTB】；技术服务费口径见《订单详情（门店侧）PRD》F6，本页面仅做规则告知。
- **业务规则**：
  1. 规则说明包含三条核心信息：参与异业推荐展示；平台收取技术服务费；技术服务费由门店承担、于团员订单全部核销完成后一次性从订单金额中扣除。服务费的具体收取门槛、扣费时点与金额口径唯一见《订单详情（门店侧）PRD》F6，本模块不复述具体数值。
  2. 规则说明仅通过页面右上角入口查看，进入页面时不自动展示。

### F2 选择服务项目和商品
- **功能描述**：页面主体左侧为分类栏，右侧为对应分类下的项目列表，支持选择项目并设置数量；项目列表仅展示项目信息，不展示项目图片。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 活动项目分服务项目与商品两大类：服务项目按洗剪吹、染发、烫发、护理、造型、美容六类划分，商品单独一类。本规则为全项目「活动项目分类」的唯一口径。
  2. 每个项目展示名称、类型（服务项目/商品）及价格：服务项目按次计费，商品按件计费。
  3. 项目支持选中与取消选中，选中后默认数量为 1；数量支持加减调整，减至 0 时取消选中。
  4. 已选项目在列表中高亮标识。
  5. 可选项目的来源范围：由【RTB】提供，须已上架且信息完整（名称、分类、原价）；服务项目缺图时由系统自动生成匹配图片（见《活动详情 PRD》F10），商品不参与图片生成。

### F3 已选项目弹层
- **功能描述**：展示当前已选的项目清单，包含项目名称、类型、单价及数量，并汇总合计原价，支持移除单项。本模块为全项目「已选项目弹层」的唯一口径，《活动配置 PRD》F6 引用本模块。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 未选择任何项目时，展示「暂未选择任何项目」。
  2. 已选项目按选择顺序展示。
  3. 合计原价即活动原价（计算规则见《活动配置 PRD》F5）。
  4. 移除单项后，已选清单与底部汇总同步更新。

### F4 底部汇总与进入下一步
- **功能描述**：页面底部展示已选项目数量与原价合计，并提供进入活动配置页的入口。
- **数据来源**：数据来源于【RTB】。
- **业务规则**：
  1. 已选数量为所有已选项目数量之和；原价合计即活动原价（计算规则见《活动配置 PRD》F5）。
  2. 未选择任何项目时不可进入下一步。
  3. 进入活动配置页时携带已选项目；活动配置页功能见《活动配置 PRD》，本页面不涉及折扣、标签等配置项。

### F5 编辑模式
- **功能描述**：从「我的活动」进入编辑流程时，页面标题切换为「编辑活动」，并预填该活动已有的已选项目。
- **数据来源**：预填数据来源于【RTB】。
- **业务规则**：
  1. 编辑模式下页面标题为「编辑活动」。
  2. 编辑模式下预填该活动已有的已选项目。
