入口漏水 · G01–G02

G01 · 「先随便看看」跳过选方向

发生在：选方向页 → 点跳过 → 进热区首页
流失可能性：高 — 一键进首页，没有后续「猜你想先做」类承接；推演约五分之一人会跳过。
建议怎么堵：跳过后仍弹轻量三选一；或跳过只是推迟提问，第一次返回再问。
优先级：P0

G02 · 四卡并列，没有默认推荐

发生在：选方向决策
流失可能性：中 — 没有「推荐」标记时犹豫成本高，容易点跳过（叠加 G01）。
建议怎么堵：按开店画像默认高亮一卡（如新店推管店或获客）；其余三卡仍保留。
优先级：P1

管店漏水 · G05 / G06 / G08

G05 · 引导一点「跳过」，这轮就再也不出现

发生在：管店各步引导（配价目、去开单等）
流失可能性：高 — 「先配一个价目」可跳过；跳过后管店主链失去编排入口。
建议怎么堵：跳过改为「稍后提醒」；首页常驻「继续开店任务」。
优先级：P0

G06 · 价目没保存，员工引导接不上

发生在：价目空态 → 保存成功 → 再衔接到员工
流失可能性：中 — 在价目页返回 / 关闭而未保存，则不会出现员工引导。
建议怎么堵：未完成就返回时，给「价目还没做好」挽回提示。
优先级：P1

G08 · 开单步骤多，中途易掉队

发生在：选客户 → 加项目 → 选员工 → 结账 → 支付 → 成功 → 流水
流失可能性：中 — 步骤多；中途退出虽可能有挽回，但长链完成率天然偏低。
建议怎么堵：缩短必经步、展示进度，或提供「稍后继续开单」明确入口。
优先级：P1

获客漏水 · G10–G12

G10 · 发布活动暗暗依赖已有项目

发生在：获客首页发布 → 建项 / 配置
流失可能性：中 — 新店空态若没有项目，发布链停在中途。
建议怎么堵：发布前发现没项目时，引导「一键示例项目」或跳去管店价目。
优先级：P1

G11 · 「我的活动」讲完后过早安静

发生在：广场 → 我的活动卡片教练 → 静默
流失可能性：高 — 安静之后，直到用户主动退出才有转化窗；人可以长期停在广场无下一动作。
建议怎么堵：安静只关掉教练气泡，空闲时再问「要不要去管店」；或发布成功后主动出转化。
优先级：P0

G12 · 获客第二次退出，跳过「再选方向」

发生在：获客退出转化已看过 → 再退出
流失可能性：中 — 第一次有转化窗，第二次直接回首页，横向转化机会丢了。
建议怎么堵：第二次退出仍进再选；或给「继续获客 / 去管店」二选一。
优先级：P1

小店漏水 · G13–G14

G13 · 小店欢迎窗可跳过，且没有强承接

发生在：小店首页欢迎窗
流失可能性：中 — 跳过后停在首页，新手指南变成可选芯片。
建议怎么堵：跳过仍在首页插一条「3 步上手」非弹窗提示条。
优先级：P1

G14 · 小店缺一个可衡量的「第一件做成的事」

发生在：新手指南结束 → 回首页
流失可能性：中 — 读完指南≠完成经营动作，退出转化依据弱。
建议怎么堵：指南末步绑一个可点击完成态（如「关联供应商」完成）。
优先级：P2

横向回流 · G16–G18

G16 · 四条路二次退出，落点各不一样

发生在：各分支「逛完了」再次触发
流失可能性：高 — 同一心智「我逛完了」却得到四种下一跳，横向转化不可预期；学习二次甚至被强塞管店。
建议怎么堵：统一二次退出 → 再选方向；禁止静默改道到管店。
优先级：P0

G17 · 再选方向里点「随便看看」，没有下一动作

发生在：再选方向窗关闭
流失可能性：中 — 关掉后停在进来之前的页面，没有推荐。
建议怎么堵：关闭 = 进入推荐分支，或回到选方向。
优先级：P1

G18 · 藏起当前卡之后，缺「继续逛当前」

发生在：再选方向时隐藏当前已在逛的卡
流失可能性：低 — 设计合理，但误触退出的人想回去要再找入口。
建议怎么堵：增加「继续逛当前」文案按钮。
优先级：P2
